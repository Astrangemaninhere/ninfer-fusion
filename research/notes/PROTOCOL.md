# 协作协议 (agent ↔ coordinator M) — v2, 2026-09-10

## 为什么有 v2
v1 的问题（用户两次点名）："**子代理自己跑自己的，协调者没有深度参与，错误没能一开始就被发现**"。
根因是 v1 隐含的模式：`满配简报 → 长自主回合(20–45min) → 交付 → 事后复核`。
讨论只发生在回合两端的接缝上，中间全程无人参与；今天 7 个被抓到的缺陷里 **5 个是作者自己发现的、
2 个是事后复核发现的，没有一个是被提前截住的**。

## v2 的核心：一回合拆两段，思路必须先返回

### P1 · 思路段（≤10 分钟，**必须早返回**）
交付物只有三样，禁止写代码/补丁/长文档：
1. **假设或计划**（分点，每条带 `file:line` 或可执行命令）；
2. **"我可能在哪儿错"** —— 至少 2 条；写不出"可能错在哪"说明还没想清楚；
3. **一个最便宜的判别实验** —— 能区分你前两个假设的那一个。
返回后**停下等 M 的批评**，不要继续。

### M 的批评（协调者的义务，不可跳过）
对每条 P1 必须：
- 核实其 `file:line` / 命令断言**是否属实**（自己 grep/读，不转述）；
- 补上**我认为缺的角度**，以及我已知而你不知道的事实；
- 点出**这一类工作常见的错误模式**（例：自我指涉的自检、假不变量、先分配后驱逐、
  半提交状态、把"脚本参数错"当成"引擎缺陷"）；
- 给出**我认为最可能的答案**（哪怕只是排序），让你来反驳。
**M 没有回应 ⇒ 不得进入 P2。** 只在极少数纯机械回合可免 P1，且该回合必须自报"无需 P1"。

### 共识 → P2 · 执行段
M 写一句共识（写进 `board.md` 的该行），然后才开工。P2 里若发现 P1 的假设被推翻，
**立刻返回**并说明，不要硬着头皮把 P2 做完。

## 仍然有效的 v1 硬规则
1. **一回合一个产物**，有 done 判据（`bash -n` / exit 0 / 数字可复现）；纯调研不算完成。
2. **报告 ≤10 行**：① 改/建了什么（绝对路径）② 一条可复制验证命令 ③ 结果数字 ④ BLOCKED/OPEN。
3. **互相验收**：不允许只自证；作者不得在自己那行写"已验证"。
4. **状态只认 `board.md`**（DOING/DONE + 产物 + 验证命令）。
5. 产出补丁而不是直接改 `src/**`（批量编译见窗口脚本）；`src/**` 的写入权归窗口。

## 环境纪律（2026-09-10 实测得来，别再踩）
- **GPU**：W9 训练占用中（起停见 board 的 GPU 行）；分派 GPU 工作前先看该行。
- **WSL 环境变量不跨界**：WSL 里 `export` 的东西 Windows 进程看不到（除 `WSLENV`）；
  需要 Windows 侧变量的脚本（如 `DF2_CACHE`）必须写在 `.bat` 里。
- **解释器归属**：`eval_ddtree.py`/`train_dflash2.py` 是 **Windows python** 脚本（硬编码 Windows 路径 +
  Windows torch）；`tools/archkit/**` 多为 WSL python。跑之前先确认，否则报的错是假的。
- **进程寿命**：`start /b` 起的子进程会随调用者结束被清掉；要独立存活必须
  `powershell Start-Process`（训练就是这么拉起来的）。
- **一次性命令**：避免在 `printf`/双引号里放反引号（会被当命令执行、写脏文件）；
  写文件用 Write 工具 + `cat >>`。
- **绝不编辑正在执行的脚本**（实测代价）：bash 是**增量读取**脚本文件的，运行中改它会让新行被当成命令执行。
  2026-09-10 的实例：给正在跑的 `_e8_muse_check.sh` 加注释 ⇒ `grep: whole: No such file or directory`
  （注释文字被当命令），该脚本的当轮 verdict 作废。**要改就先复制成新文件名，或等它结束。**
- **杀进程一律按 PID**：`pkill -f '<pattern>'` 会匹配到**你自己的命令行**（同日实例：`pkill -f '_muse_discriminators.sh'`
  把我自己的 shell 杀了）。先 `tr '\0' ' ' < /proc/<pid>/cmdline` 核对，再 `kill -9 <pid>`。
- **同一 20GB 模型不要开两个实例**：Muse 双实例实测把 31.8GB 显存吃到只剩 334MB。GPU 工作前先看
  `nvidia-smi` 与正在跑的 serve/CLI，串行安排。
- **构建**：只用窗口脚本（`_window_h.sh` 等）；单个补丁单独开窗口 = 烧 30 分钟，纪律是**攒批**。
